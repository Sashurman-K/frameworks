# Система учета достижений студентов

## Назначение проекта
Программа предназначена для фиксации, группировки и проверки индивидуальных достижений студентов (олимпиады, научные публикации, спортивные и культурные мероприятия).

## Целевая аудитория
Студенты, старосты групп, кураторы и сотрудники деканата.

## Предметная область
Учет внеучебной и академической активности студентов высших и средних учебных заведений.

## Основные сущности
* **Студент** (`student`)
* **Достижение** (`achievement`)
* **Категория** (`category`)
* **Подтверждение** (`confirmation`)

## Основные функции
1. Создание записи о новом достижении студента.
2. Проверка статуса подтверждения достижения.
3. Формирование текстового отчета о достижениях студента.
